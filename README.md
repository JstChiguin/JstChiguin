# 📂 Proyectos Destacados


## 🏥 ADMEDH — Sistema de Gestión Médico-Administrativa Hospitalaria

**Proyecto personal · En desarrollo · by Chiguin**

ADMEDH es una aplicación web de gestión médico-administrativa que desarrollo a partir de necesidades reales identificadas en procesos hospitalarios.

El proyecto utiliza una arquitectura frontend modular basada en React, con componentes reutilizables y separación de responsabilidades entre presentación, lógica de negocio y acceso a datos.

La autenticación y persistencia se gestionan mediante servicios Firebase, mientras que los entornos de ensayo y principal se mantienen separados para reducir riesgos durante el desarrollo y despliegue.

Su objetivo es centralizar información, reducir tareas repetitivas, mejorar la trazabilidad de los registros y facilitar la gestión mediante una interfaz adaptable a computadores, tablets y dispositivos móviles.

### ✨ Principales funcionalidades

- 👨‍⚕️ Gestión de profesionales médicos y programación horaria.
- 📅 Horarios, vigencias, modificaciones y cobertura asistencial.
- 📝 Permisos, ausentismo y registros administrativos.
- 🏥 Gestión de censos, hospitalizaciones y movimientos.
- 🩺 Interconsultas y seguimiento de registros.
- 📋 Documentos, formularios y reportes.
- 📊 Estadísticas y exportación de información.
- 👥 Administración de usuarios, roles y permisos.
- 🔐 Autenticación y restricciones de acceso mediante Firebase.
- 🧾 Auditoría y trazabilidad de operaciones.
- ⏳ Gestión de sesiones y cierre por inactividad.

### 🏗️ Arquitectura y tecnologías

**Frontend:** React, JavaScript, Vite, HTML5 y CSS3.

**Backend y servicios:** Firebase Authentication y Cloud Firestore.

**Herramientas:** Git, GitHub, ExcelJS y Firebase Hosting.

El proyecto utiliza una arquitectura modular, con separación de responsabilidades y componentes reutilizables, facilitando su mantenimiento y evolución.

### 🧪 Desarrollo y pruebas

ADMEDH está organizado para trabajar con dos entornos independientes:

- **`develop` — Ensayo:** versión de pruebas con usuarios y registros ficticios, destinada a validar funcionalidades, permisos y cambios.
- **`main` — Principal:** versión destinada a recibir los cambios previamente validados en el entorno de ensayo.

La estrategia de desarrollo contempla pruebas automatizadas, controles de acceso y verificaciones de aislamiento entre los proyectos Firebase, junto con despliegues independientes mediante GitHub Actions.

**La configuración de integración y despliegue continuo se encuentra en proceso de implementación y validación.**

### 🔐 Seguridad

La aplicación incorpora autenticación, control de acceso basado en roles, reglas de seguridad de Firestore y trazabilidad de operaciones.

El desarrollo considera la protección de información sensible, la separación de entornos y el uso de datos sintéticos para las pruebas.

### 🚧 Estado del proyecto

**En desarrollo activo — repositorio privado.**

Proyecto de autoría personal, desarrollado con fines de aprendizaje, innovación y evolución profesional.

*ADMEDH no constituye un sistema institucional oficial ni implica adopción o aprobación por parte de una institución de salud.*

## 🌱 ParvuLog

Aplicación web nacida a partir de una necesidad real identificada durante una clase universitaria. Una docente comentó las dificultades que enfrentaba para registrar y organizar experiencias pedagógicas, lo que dio origen a la idea de desarrollar una herramienta que simplificara ese proceso.

A partir de esa necesidad desarrollé **ParvuLog**, una aplicación que permite registrar experiencias mediante voz o texto, organizar observaciones y generar informes. Una semana después de identificar el problema, la primera versión funcional fue entregada a la docente como solución para apoyar su trabajo.

### ✨ Características

* 🎙️ Registro mediante reconocimiento de voz
* 📝 Edición manual
* 📒 Bitácora diaria
* 👧 Registro de participantes
* 📄 Generación de informes
* 🖨️ Impresión
* 📄 Exportación a Word (.docx)
* 💾 Almacenamiento local

### 🛠️ Tecnologías

HTML • CSS • JavaScript • Web Speech API • Docx.js

## 📚 Irregular Verbs

Aplicación web desarrollada a partir de una necesidad personal: aprovechar mis trayectos diarios hacia y desde el trabajo para estudiar verbos irregulares en inglés sin depender de mirar constantemente una pantalla.

La aplicación está orientada especialmente al **aprendizaje mediante audio**, permitiendo escuchar los verbos, repetirlos automáticamente y organizar la práctica por grupos mientras realizo otras actividades.

Actualmente evalúo su evolución hacia una **aplicación móvil con integración para el sistema multimedia del automóvil**, manteniendo como objetivo principal facilitar el estudio mediante audio durante los trayectos.

### ✨ Características

* 🔊 Reproducción automática mediante síntesis de voz
* 🔁 Repetición configurable
* 📂 Selección por grupos
* 🔇 Exclusión individual de verbos
* 🎧 Bucle por grupo
* 🔄 Reproducción independiente por grupos
* 📱 Diseño responsive

### 🛠️ Tecnologías

HTML • CSS • JavaScript • Web Speech API
